직접 수정본을 유지하고 있습니다. 입력폼 변경을 반영하려면 다시 생성하세요.

사용 방법 / 저장 안내

구분 선택 시 시작시간은 OF 09:00, SW 13:00으로 자동 설정되며 직접 수정할 수 있습니다. 구분을 변경하면 종료시간은 공백으로 초기화됩니다. 시작·종료시간은 24시간 HH:MM 형식이며, 0925를 입력하면 09:25로 표시됩니다. Issue·작업내용·교체품은 영문 A–Z, 한글 가나다순입니다. 장비 모델은 카톡 일보 등장 빈도순(O3, O2, C4, C3, O5)입니다. 문구 드롭다운을 고르면 해당 입력란에 반영됩니다. 작업내용은 문구를 골라 ‘추가’를 누르면 한 줄씩 쌓이며, 입력란에서 자유롭게 수정할 수 있습니다. 교체품과 킷 파츠는 항목을 고른 후 ‘추가’를 누르면 쉼표로 이어집니다. ‘기타 · 직접 입력’은 직접 입력한 항목도 추가할 수 있습니다. ‘기타 · 직접 입력’을 고르면 수동 작성할 수 있습니다.

입력 내용은 현재 브라우저에 자동 저장됩니다. 시크릿 모드나 일부 파일 뷰어에서는 저장이 제한될 수 있습니다. HTML은 JavaScript가 실행되는 브라우저에서 열어 주세요. 복사가 제한되면 미리보기의 텍스트를 전체 선택해 복사할 수 있습니다. 외부 서버로 전송하는 기능은 없습니다.
